# Yacht Adventures ⛵

A yacht rental landing page built as a team HTML/CSS learning project at GoIT.

**[View live website](https://valeriy-zinkovskyi.github.io/yacht-adventures/)** · **[Original team repository](https://github.com/GoitStudentsWorks/html-css_92_-Debeluk)**

## My contribution

I implemented the **hero section — the first screen of the landing page**, including its HTML structure and CSS styling:

- The main heading, introductory text, and call-to-action button layout.
- The visual composition with the yacht, client portraits, and owner image.
- Typography, spacing, colors, and positioning within this section.

This was a collaborative project. My contribution covers the hero section; the complete website was created by the team.

## Project overview

The page presents a yacht rental service with sections for:

- An introduction to Yacht Adventures.
- Information about the service and its fleet.
- Yacht cards with specifications.
- Activities such as diving, fishing, and sunbathing.
- A rental inquiry form.
- Customer reviews.

This is an educational frontend demonstration. The presence of a form does not imply a working booking service or backend integration.
